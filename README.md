# Emmanuel Selestini Deusi - Portfolio
Static site, no build step.

- Pages: `index.html`, `work.html`, `design.html` (poster gallery), `about.html`, `contact.html`
- Each project has its own page in `work/` (e.g. `work/titanic-survival.html`)
- Images: `images/` (profile photo, backgrounds, `posters/`); CV files: `files/`

Deploy: push to GitHub, import the repo in Vercel (Framework: Other, no build command, output directory: root).
