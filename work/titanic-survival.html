Titanic Survival Prediction

End-to-end ML pipeline comparing Random Forest, SVM and Neural Networks. 84.4% cross-validation accuracy.

Overview

An end-to-end machine learning pipeline for the classic Kaggle Titanic competition: predicting which passengers survived from information such as age, sex, ticket class and fare. The aim was to practise the full workflow a real healthcare prediction model needs, on a well-known dataset.

Process

  1. Data cleaning. Handled missing ages, fares and embarkation ports, and checked every column for errors.
  2. Feature engineering. Built new features from the raw columns to give the models more signal.
  3. Model comparison. Trained and compared Random Forest, Support Vector Machine and Neural Network models.
  4. Hyperparameter tuning. Tuned each model with cross-validation to avoid overfitting.
  5. Evaluation. Reached 84.4% cross-validation accuracy, all documented in a reproducible Jupyter notebook.

Why it matters

The same steps are used for clinical prediction: cleaning messy patient records, choosing features, and validating a model before anyone relies on it.
